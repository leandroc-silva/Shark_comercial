# Shark Attack FC — Proposta Comercial

Proposta comercial digital desenvolvida para apresentar o Shark Attack FC a potenciais parceiros e patrocinadores.

O projeto organiza informações sobre o time, alcance digital, formas de exposição da marca e planos de parceria em uma página responsiva e preparada para visualização digital e impressão em PDF.

## Sobre o projeto

O Shark Attack FC é um time de futebol amador de Cascavel, Paraná, fundado em dezembro de 2023.

O objetivo deste projeto foi criar uma apresentação comercial visual e organizada para apoiar a busca por parceiros, apresentando:

- Informações sobre o projeto esportivo;
- Alcance digital do time;
- Dados da audiência;
- Formas de exposição para parceiros;
- Planos de parceria;
- Parceiros atuais;
- Proposta visual da faixa de parceiros;
- Informações para contato comercial.

## Tecnologias utilizadas

- HTML5
- CSS3

## Funcionalidades

- Navegação entre as seções da página;
- Layout responsivo;
- Links para Instagram e WhatsApp;
- Organização visual dos planos de parceria;
- Apresentação de métricas de alcance digital;
- Estilização específica para impressão e geração de PDF.
